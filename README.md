# RoadSense
### Crowd-Sourced Vehicular Road Condition Monitoring System

RoadSense is an intelligent vehicular telemetry system designed to detect and classify road anomalies such as potholes, speed breakers, and varying levels of road roughness through vibration signature analysis and geospatial event mapping.

The project aims to transform ordinary vehicles into mobile sensing platforms capable of continuously monitoring road infrastructure and generating crowd-sourced road quality data for smarter transportation and infrastructure planning.

---

## Features

- Real-time road anomaly detection
- Pothole identification and logging
- Speed breaker detection
- Road roughness classification
- GPS-based event tagging and mapping
- Telemetry data acquisition and storage
- Adaptive calibration and signal processing
- Crowd-sourced road condition monitoring framework

---

## System Overview

The system continuously acquires vehicle vibration and location data while the vehicle is in motion. Signal processing algorithms analyze vibration signatures to identify road anomalies and classify road conditions.

### Detection Capabilities

- Pothole Detection
- Speed Breaker Detection
- Road Roughness Monitoring

### Data Captured

- Timestamp
- GPS Coordinates
- Vehicle Speed
- Vibration Intensity (Delta)
- Event Classification

---

## Methodology

1. Sensor calibration establishes a baseline vibration profile.
2. Real-time vibration data is continuously monitored.
3. Signal processing algorithms calculate vibration intensity variations.
4. Road anomalies are classified using threshold-based detection logic.
5. Detected events are tagged with GPS coordinates and logged for analysis.

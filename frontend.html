1
Accelerometer Magnitude

The MPU6050 outputs raw 16-bit signed integers for acceleration on three axes (X, Y, Z) at ±2 g full-scale range. Each axis reading is first converted to physical units using the sensitivity scale factor:

a_x = raw_x / 16384.0  — units: g (gravitational acceleration)
a_y = raw_y / 16384.0
a_z = raw_z / 16384.0

M_i = √(a_x² + a_y² + a_z²)  — Euclidean magnitude of acceleration vector

For road classification, the Z-axis dominates because the sensor is mounted vertically in the vehicle — vertical road impulses couple almost entirely to Z. However, using full 3-axis magnitude makes the system orientation-invariant: the sensor doesn't need to be perfectly aligned.

2
Baseline Calibration & Delta (Δ)

Before each run, the car is held stationary for 5 seconds. During this window, N₀ ≈ 48 readings are collected. The baseline is the rolling mean magnitude of the stationary sensor:

M̄_baseline = (1/N₀) · Σᵢ M_i  — average magnitude while stationary

Δ_i = |M_i − M̄_baseline|  — absolute deviation from rest state

This gives a relative vibration score per reading. On smooth asphalt at cruise speed, Δ ≈ 0–4,000. At a pothole impact, Δ spikes above 7,000. This is not a universal unit — the same pothole on a different vehicle with stiffer suspension would produce a different Δ value.

⚠ Δ is device and session-specific. The values displayed (7,424 – 11,506) were computed from this MPU6050 (baseline 702.13), mounted in this Maruti 800, on this run. Repeating with a different sensor, bracket, tyre pressure, or vehicle will yield different numbers for the same physical potholes.

3
Event Detection Thresholds

An event fires when Δ_i exceeds a tuned threshold θ for at least one consecutive sample. Thresholds were set by driving over a known pothole and known speed breaker during a calibration pass:

— Pothole detection —
if Δ_i > θ_pothole (= 7,702) → flag as pothole candidate

— Speed breaker detection —
if Δ_i > θ_breaker (= 8,987) → flag as breaker candidate
   AND sustained for > 150 ms → confirm as breaker

— Road surface classification —
if Δ_i < 7,000 → GREEN (smooth)
if Δ_i ∈ [7,000, 11,000] → YELLOW (moderate)
if Δ_i > 11,000 → RED (rough)
4
Severity Classification (HIGH / MED / LOW)

Each confirmed pothole and speed breaker event is further classified by peak Δ into a severity band for quick triage:

HIGH  : Δ_peak > 10,000  — 3 potholes, 3 breakers in this run
MED   : Δ_peak ∈ [8,500, 10,000]  — 5 potholes, 2 breakers
LOW   : Δ_peak < 8,500  — 4 potholes, 2 breakers

These bands were chosen so that HIGH events correspond to impacts that would cause measurable tyre and suspension wear on a standard sedan over repeated exposure. They are not standardised — a future version would cross-validate against IRI (International Roughness Index) measurements from a reference profilometer.

5
Spatial Deduplication (75 → 12 potholes)

A single pothole can trigger multiple IMU spikes as the tyre bounces. Raw log contained 75 triggers. These were collapsed using Haversine distance clustering:

— Haversine distance between two GPS points —
a = sin²(Δlat/2) + cos(lat₁)·cos(lat₂)·sin²(Δlon/2)
d = 2·R·arcsin(√a)  — R = 6,371 km

— Clustering rule —
if d(e₁, e₂) < 50 m → merge into single event (keep max Δ)

75 raw triggers → 12 unique pothole locations

The representative GPS coordinate for each cluster is the centroid of all member events. The representative Δ is the maximum observed within the cluster — worst-case severity is used for road reporting.

6
Road Quality Index (RQI)

A simple summary score is derived from the proportion of GREEN samples in the total reading set:

RQI = (N_green / N_total) × 100%

RQI = (6,283 / 7,953) × 100% = 79.0%

RQI is a qualitative approximation — not a certified IRI score. To convert to a standardised roughness index, sensor output would need to be calibrated against a reference profilometer on a known surface. The RQI nevertheless gives a useful single-number summary for comparing different road segments or repeat runs on the same corridor.

ℹ Future work: Cross-validating Δ against IRI (m/km) on a stretch with known profilometer data would allow us to derive a transfer function — turning this into a certified roughness measurement tool usable by municipal road authorities.
7
Speed Breaker Crossing Duration

Duration is the elapsed time from the first sample that exceeds θ_breaker to the first sample that falls back below it:

t_start = timestamp of first sample where Δ > θ_breaker
t_end   = timestamp of first sample where Δ < θ_breaker (post-peak)

Duration = t_end − t_start  — in milliseconds

Range in this run: 265 ms – 318 ms  mean = 292 ms

Duration is inversely correlated with crossing speed (faster crossing → shorter duration). Combined with Δ, it helps distinguish a tall breaker crossed slowly from a shallow breaker crossed fast — both can produce similar Δ but will have very different durations.
